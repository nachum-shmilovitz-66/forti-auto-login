Forti Auto Login @VERSION@

Fills in the FortiClient VPN token code for you. When FortiClient asks for the code that was mailed to you, Forti Auto Login reads it from Gmail in Google Chrome, types it in, clicks OK, and closes the FortiClient window once the VPN is up.

This installer puts the app in your Applications folder and starts it when it finishes. A running older version is closed and replaced.
