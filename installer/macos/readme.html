What happens after installing

The app starts by itself and shows a shield icon in the menu bar, at the top right of the screen. It asks for these once:

  1. Settings window: enter the email address that receives the FortiClient AuthCode mail, then click Save & Restart.
  2. Accessibility: macOS asks to let Forti Auto Login control your computer. Click Open System Settings and switch Forti Auto Login on.
  3. Automation: when asked, allow Forti Auto Login to control System Events and Google Chrome.
  4. Chrome: Chrome must be signed in to that Google account. In a window of that Chrome profile, choose View > Developer > Allow JavaScript from Apple Events.

Optional: System Settings > General > Login Items > add Forti Auto Login, so it starts after a restart.

If a login is not filled in: click the shield icon > Report a Problem… and send the zip file it creates.
